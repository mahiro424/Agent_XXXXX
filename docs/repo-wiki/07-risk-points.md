# 07 风险点与安全防护矩阵

本文档梳理系统运行中的潜在风险点及对应的纵深防御措施。

---

## 安全防护矩阵

| 风险场景 | 潜在威胁 | 防御实现 |
| :--- | :--- | :--- |
| **路径穿越攻击** | 恶意提示词试图写入 `C:\Windows` 或读取工作区外敏感文件 | `LocalWorkspaceSandbox.resolveInsideRoot` 强制比对规范化根路径，严防 `..` |
| **文件覆盖损毁** | 任务生成同名文件意外覆盖用户原有的源数据 | `LocalWorkspaceSandbox` 写入前强校验文件存在性，禁止静默覆写 |
| **模型幻觉假完成** | 大模型声称已完成生成，但实际未写入文件 | `EvidenceVerifier` 独立物理检查磁盘真实产物，要求 OpenXML 结构完整且可解析 |
| **异常断电重复执行** | 系统重启后重复执行收费或外部有副作用的命令 | 状态机自动标识 `RECONCILIATION_REQUIRED`，强制锁定现场 |
| **模型名填错报错** | 用户手动输入错误模型名导致 400 Model Not Found | 【🔄 获取可用模型】自动请求 `GET /models` 动态生成下拉列表，杜绝笔误 |
